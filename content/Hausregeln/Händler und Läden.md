## Laden Modifikatoren
Trage folgende Werte in Absprache mit meinem DM in dem [[Händler und Laden Sheet]] ein.

| Versorgung         | Versorgungslage     | Ladengröße      | Diverse Modifier   |
| ------------------ | ------------------- | --------------- | ------------------ |
| täglich            | exzellent (+2)      | riesig (10)     | spezialisiert (+2) |
| zwei mal pro Woche | gut (+1)            | groß (8)        |                    |
| wöchentlich        | geht so (+0)        | mittel groß (6) |                    |
| alle zwei Wochen   | schlecht (-1)       | klein (4)       |                    |
|                    | Les Misérables (-3) |                 |                    |
**Versorgung** beschreibt wie oft dieser Laden neue Ware geliefert bekommt.
Sollten die Spieler alle Slots eines Ladens aufgebraucht haben, können sie erst nach Ablauf dieser Frist weitere Waren kaufen.

Die **Versorgungslage** beschreibt wie viel Ware der Händler auf Lader hat. Der angegebene Wert wird einfach zu dem Würfelwurf addiert.

Die Ladengröße beschreibt wie viele unterschiedliche Waren der Laden anbietet. Die Spieler können mehrfach auf die selben Items würfeln, verbrauchen aber jedes mal einen Slot.
Die Preise konnen in der [Preistabelle][Preistabelle.base] nachgesehen werden. Sollte bei "Modifikator" kein Wert angegeben sein, handelt es sich um Waren die den Spielern quasi endlos zu Verfügung stehen.

## Gegenstände kaufen
Wenn die Spieler einen Gegenstand kaufen möchten, müssen die zunächste auf dem [[Händler und Laden Sheet]] des jeweiligen Ladens nachsehen, ob der Laden noch einen Slot frei hat.
Ist dies der Fall würfeln die Spieler 1d8 und addieren sämtliche Modifikatoren. Das Resultat ist die Menge der zum Verkauf angebotenen Gegenstände des jeweiligen Typs.
Das heißt ein Resultat <= 0 bedeutet der jeweilige Gegenstand ist ausverkauft.

Die Spieler können mehrfach auf den selben Gegenstand würfeln, solange der Laden noch freie Slots hat.
### Kritischer Erfolg
Wenn die Spieler eine 8 würfeln, dürfen sie einen weiteren 1d8 würfeln.
Dieser Schritt wird so oft wiederholt, bis keine 8 mehr gewürfelt wird.

## Beispiel
Pia möchte für Trix eine [[Plattenrüstung]] kaufen (warum auch immer sie das tun würde). Sie schaut im Regelwerk nach und findet für die Plattenrüstung folgende Traits & Groups: "heavy", "plate", "common", sowie das item lvl von 2.
Daraus ergibt sich folgender Modifikator:

heavy: -4
plate: -4
common: -0
item lvl: -(2/2) = -1

**Grundmodifikator**: -9

Glücklicherweise befinden sich unsere Helden in einer gut ausgestatteten Stadt und sie haben einen großen, spezialisierten Laden gefunden.
Daraus ergibt sich folgender Modifikator:

gute Versorgunslage: (+1)
spezialisierter Laden: (+2)

endgültiger Modifier: -9 + 3 = -6

Pia trägt die [[Plattenrüstung]] in einem der acht Slots (siehe großer Laden) auf den [[Händler und Laden Sheet]] ein und würfelt 1d8. Leider würfelt sie eine 6, verrechnet mit dem Modifier ergibt das 0 angebotene Rüstungen.
Sie entscheidet sich dazu es nochmal zu versuchen und würfelt jetzt eine 8, würfelt noch einmal und bekommt eine 1. Das bedeutet der Laden hat doch 8 + 1 - 6 = 3 Rüstungen im Angebot.
