# Leder
Rüstung, gefertigt aus den gegerbten Häuten diverster Tiere. Auf Grund der relativen Flexibilität dieses Werkstoffs können aus ihm gefertigte Rüstungen einen allumfassenderen Schutz bieten. Das liegt vorallem daran, dass sich bei Bewegungen keine Öffnungen in der Rüstung auftun.  
Träger von Lederrüstungen erhalten Resistenz gegenüber Schaden vom Typ "Precision" in Höhe von:

| Kategorie | Schadensreduktion | Typ       |
| --------- | ----------------- | --------- |
| Leicht    | 2 + AC + Rune     | Precision |
| Mittel    | 4 + AC + Rune     | Precision |
# Komposit
Diese Rüstungen bestehen aus vielen verschiedenen, sich überlappenden Teilen. Träger von Kompositrüstungen erhalten Resistenz gegenüber kritischen Treffern in Höhe von:

| Kategorie | Wert                | Typ               |
| --------- | ------------------- | ----------------- |
| Leicht    | 2 + (2 * AC) + Rune | kritische Treffer |
| Mittel    | 4 + (2 * AC) + Rune | kritische Treffer |
| Schwer    | 8 + (2 * AC) + Rune | kritische Treffer |
# Gepolstert
Mehrere Schichten aus Wolle oder Leinen verteilen die Wucht von Angriffen auf eine größere Fläche. Träger von gepolsterten Rüstungen erhalten Resistenz gegenüber Schaden vom Typ "Bludgeoning" in Höhe von:

| Kategorie | Wert          | Typ         |
| --------- | ------------- | ----------- |
| Leicht    | 2 + AC + Rune | Bludgeoning |
| Mittel    | 4 + AC + Rune | Bludgeoning |
# Kette
Kettenhemden bestehen aus hunderten und aberhunderten kleiner Metallringe. Diese bieten dem Träger einen recht effektiven Schutz gegenüber Schnitten. Träger von Kettenhemden erhalten Resistenz gegenüber Schaden vom Typ "Slashing" in Höhe von:

| Kategorie | Wert          | Typ      |
| --------- | ------------- | -------- |
| Leicht    | 2 + AC + Rune | Slashing |
| Mittel    | 4 + AC + Rune | Slashing |
# Platte
Solide Platten aus Metall. Diese bieten dem Träger einen recht effektiven Schutz gegenüber Projektilen jedweder Art. Träger von Plattenrüstungen erhalten Resistenz gegenüber Schaden vom Typ "Piercing" in Höhe von:

| Kategorie | Wert          | Typ      |
| --------- | ------------- | -------- |
| Mittel    | 4 + AC + Rune | Piercing |
| Schwer    | 8 + AC + Rune | Piercing |
